# WNBA Accuracy Page — Phase 1 Audit (data-source trace)
*2026-07-10 · read-only audit, no code changed in this phase*

## Verdict
The two headline cards on `/accuracy/wnba` ("Verified accuracy" and "Season verified results")
are **best-bet betting results**, not projection accuracy. Proven: the manifest's
`learning.accuracy = 0.5303529411764706` equals `graded_bets.csv` win/(win+loss) = 1127/2125 to
1e-9. **63% of those graded rows are over/under bets on sportsbook lines, and 1,363 of 2,175 are
combo props (pa/pr/pra/ra).** The card caption ("stat-line predictions graded against final box
scores") is therefore misleading — it is a bet hit rate on selected sides, including combos.

The genuine projection-vs-box-score grading **already exists** in
`learning/errors/projection_errors.csv` (11,424 archive-graded rows, MAE 1.63) but is **not read by
the accuracy page at all.**

Coverage of `projection_errors.csv`: **points, rebounds, assists, threes_made, steals, blocks**
(6 stats, 47 slates, 2025-07-05 → 2026-07-09). Generated by `update_wnba_learning_outputs.py`
from `outputs/archive/projections/wnba_projections_*.csv` via `STAT_PROJECTION_MAP`.

**Not yet graded (gaps to close in Phase 2):**
- Combos **PRA/PR/PA/RA** — projection columns exist in archives (`PRA_PROJ` etc.), just not in the map.
- **Turnovers** — ❌ **no `TO_PROJ` column is published in the archives**; the projection engine does
  not project turnovers. This is an honest exclusion, not a bug (documented in Phase 6).
- **Minutes** — graded in `minutes_errors.csv`, just not shown.

## Deploy topology (for Phase 7)
- Source-of-truth: `site/nba_model/webapp/accuracy_views.py`; WNBA base resolves to
  `sports/wnba` (`_resolve_wnba_base`, `:85`).
- Prod serves `/srv/edgeranked-prod/...`; loaders fall back across `PROJECT_ROOT` then
  `SITE_DATA_ROOT`. Editing `site/` does **not** change the live site until deployed (surgical cp +
  restart). No projection/best-bet/gate code is in scope.

## Design mandate confirmed
- Projection accuracy (Cards 1–2 redesign + analytics) must read **only** `projection_errors.csv`
  / `minutes_errors.csv` / a new projection-accuracy report — never `graded_bets.csv`,
  `wnba_bets_history.csv`, `bet_result`, `hit_rate`, `line`, or `side`.
- Best-bet metrics move to a separate "Best Bet Performance" section (Phase 5) that keeps using
  `graded_bets.csv`.
- Regression test (Phase 7) will assert the projection loaders never touch a bet artifact.
